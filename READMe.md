## 👥 Labor & Operational Cost Structure
The factory's monthly human resource overhead is systematically managed across a 4-week cycle totaling **10,000,000 SYP**, distributed as follows:
*   **Chief Supervisor (El-Rayes):** 600,000 SYP / week
*   **Master Cutting Technicians (Tables):** 500,000 SYP / week
*   **Stitching & Overlock Masters (Male/Female):** 400,000 SYP / week each
*   **Packaging & General Assembly Staff:** 200,000 SYP / week each
